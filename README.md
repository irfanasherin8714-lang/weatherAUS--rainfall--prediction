# 🌧️ WeatherAUS Rainfall Prediction

## 📌 Project Overview
This project predicts whether it will rain tomorrow using the WeatherAUS dataset. It includes data preprocessing, exploratory data analysis (EDA), feature engineering, model training, and evaluation using a Random Forest Classifier.

## 🎯 Objective
- Predict rainfall for the next day.
- Build an accurate machine learning classification model.

## 📂 Dataset
- Dataset: WeatherAUS
- Target Variable: RainTomorrow

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Model
- Random Forest Classifier

## 📊 Results
- Accuracy: **85%**
